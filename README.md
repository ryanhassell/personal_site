# Ryan Hassell Personal Site

Personal site built with Vite, React, and TypeScript.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run lint`

## Structure

- `src/content/siteContent.ts`: single typed content source for profile, experience, projects, skills, and contact links
- `src/pages/`: home and resume routes
- `src/components/`: shared frame and navigation
- `public/files/ryan-hassell-resume.pdf`: downloadable resume PDF

## Notes

- Routes are `/` and `/resume`
- The site is fully static and does not include a backend or contact form
- The live content is intentionally based on the current resume and omits the phone number from the public UI
